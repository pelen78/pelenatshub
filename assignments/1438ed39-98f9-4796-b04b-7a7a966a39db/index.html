Your Mission

In this lesson, you will learn some basic tools of GIMP to edit and improve images. By the end of the activity, you will be able to change the orientation of an image, crop it, and change its size.

You will find all the image files attached to this assignment in Google Classroom. Download them first. Every exercise tells you which file to use.

Why does this matter? Big images make websites slow, fill up your Drive, and sometimes can't even be uploaded. Knowing how to make an image smaller without ruining it is something you will use all year.

Today · Class 1

What we're doing right now

  1. Download the image files from Google Classroom.
  2. Create your GIMP folder on your Desktop, with the subfolder inside.
  3. Open GIMP and finish Flip horizontally and Rotate clockwise.
  4. Start Crop into 12 images.
Check-In · Getting ready

Do these steps before you start editing. Organized files now means no lost work later.

  1. Download all the files attached to this assignment: Germany, HorseheadIR-Hubble, Flower Poster, Natural Sunset, Tennis, Golf, Chess and Beach.
  2. On your computer's Desktop, create a folder called GIMP.
  3. Inside it, create a subfolder called crop_resize_rotate. Write it exactly like that: lowercase, with underscores and no spaces. All your files for this assignment go here.
  4. Move the image files you downloaded into crop_resize_rotate, so everything is in one place.
  5. Open GIMP and open your first file with File › Open.

You only export. File › Export As creates the .jpg: the finished image anyone can open. That is the only file you turn in.

The Exercises

Do the exercises in order. Every exercise ends the same way: export the .jpg into your Desktop › GIMP › crop_resize_rotate folder.

Exercise 01 · Crop

Flip horizontally

File: Germany
  1. Open the file.
  2. Go to Image › Transform › Flip Horizontally.
  3. Check it: the image should look like a mirror of the original.

Rotate clockwise

File: HorseheadIR-Hubble
  1. Open the file.
  2. Go to Image › Transform › Rotate 90° clockwise.
  3. Check it: the top of the image is now on the right side.

Crop into 12 images

File: Flower Poster
  1. Select the Crop Tool in the Toolbox.
  2. Draw a box around one flower and click inside the box to crop it.
  3. Export it as a .jpg.
  4. Go to Edit › Undo to go back to the full poster.
  5. Repeat until you have 12 separate images.

Exercise 02 · Resize

Make each image weigh between 400 and 500 KB. Use Image › Scale Image and change the width. Keep the chain icon closed so the image doesn't get stretched.

Developing · Export to .JPG

Every finished image must be a .jpg file.

  1. Go to File › Export As.
  2. Give the file a clear name that ends in .jpg, for example germany-flip.jpg or flower-07.jpg.
  3. Choose your crop_resize_rotate folder and click Export.
  4. In the JPEG window, click Export again. For Exercise 02, the Quality slider also changes the file size.
Turning it in

You turn in the link to your folder, not loose files.

  1. Make sure your Desktop › GIMP › crop_resize_rotate folder has all your .jpg files.
  2. Open Google Drive and drag your whole GIMP folder from the Desktop into My Drive. Wait until the upload finishes.
  3. Check that your crop_resize_rotate folder has 22 files.
  4. In Google Drive, open your GIMP folder, right click the crop_resize_rotate folder, click Share › Copy link, and submit the link to Google Classroom.
  5. Don't forget to write the original sizes of Tennis, Golf, Chess and Beach in the private comments.

Upload the whole GIMP folder, but share the link to crop_resize_rotate. Your next GIMP exercises will go inside the same GIMP folder, each one in its own subfolder. A folder I can't open counts as not turned in.
