What You Will Learn

Throughout Unit 3, you will learn how a programming language turns ideas into instructions a computer can run. You will also practice testing programs with different inputs and explaining how data is stored, changed, and displayed.

01

Programming Languages

  • Explain what code is and why we use programming languages.
  • Write pseudocode to plan a program before coding it.
  • Identify computing innovations and the data they use.
02

Variables & Data Types

  • Create variables with clear, meaningful names.
  • Use the assignment operator to store and update values.
  • Tell the difference between numbers, strings, and booleans.
03

Arithmetic Expressions

  • Use + - * / and follow the order of operations.
  • Use modulus % to find a remainder.
  • Join text and values with string concatenation.
04

User Input & Events

  • Ask the user for input and use it in the program's output.
  • Write programs that respond to mouse clicks and key presses.
  • Test a program with different inputs to check its behavior.
