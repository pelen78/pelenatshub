What You Will Learn

In this unit you will use programming as a tool for creativity. You will break a big picture into smaller parts, write functions for each part, and share your finished program with an audience.

01

Top-Down Design

  • Break a large problem (your image) into smaller, simpler parts.
  • Plan the order Karel needs to follow to paint each part.
02

Functions

  • Write your own functions with clear, descriptive names.
  • Reuse functions instead of repeating the same lines of code.
03

Loops & Control Structures

  • Use loops to repeat actions like painting a whole row.
  • Use conditions so Karel can react to walls and the grid.
04

Sharing a Computational Artifact

  • Understand that programs are made to be used and seen by others.
  • Embed a working program in a web page you built.
