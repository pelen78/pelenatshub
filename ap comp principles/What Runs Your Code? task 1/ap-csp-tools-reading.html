Visual Studio Code

VS Code is a code editor.

A code editor is a program made for writing and organizing computer code. Think of VS Code as a text editor built especially for programmers.

  • It recognizes programming languages and colors the code so it is easier to read.
  • It helps organize files and folders in a project.
  • It can warn you about some mistakes while you type.
  • It can add extra features through extensions.
  • It can show a Terminal inside the same window.
Important idea: VS Code helps you write and edit code. Opening a JavaScript file in VS Code does not automatically run the program.
What is an IDE?

An IDE means Integrated Development Environment. It includes a code editor plus more development tools that are already built into the same program.

The names are very similar, but they are different Microsoft products.

Do not mix up the names. Visual Studio Code = VS Code = the editor you have used. Visual Studio = a different, larger IDE. Microsoft retired Visual Studio for Mac in 2024 and recommends VS Code as an option for development on Mac.
Node.js

Node.js is a JavaScript runtime. In simple words, it gives your computer a way to run JavaScript outside a web browser.

Imagine that you create this file in VS Code:

hello.js

let name = "Alex";
console.log("Hello, " + name);

VS Code can show and edit the file, but Node.js is the tool that can execute the JavaScript instructions in that file.

Easy way to remember

VS Code = write the JavaScript.

Node.js = run the JavaScript.

The Terminal

The Terminal is a way to give instructions to the computer by typing commands instead of clicking buttons and menus.

VS Code can display a Terminal inside its window, but the Terminal and VS Code are not the same thing. On a Mac, you could also open the Terminal app separately.

Three commands you will use

node --version: asks Node.js to show its installed version.

ls: lists the files and folders in your current location on a Mac.

node hello.js: tells the computer to use Node.js to run the file named hello.js.

How the pieces work together

These tools have different jobs, but they can work together in the same project.

Youdecide what the program should do
→
VS Codewrite and edit hello.js
→
Terminaltype a command
Node.jsreads and runs the JavaScript
→
Resultthe program produces output

Simple example

1. In VS Code:
   console.log("Hello!");

2. In the Terminal:
   node hello.js

3. Result:
   Hello!
The big idea: The file is the same file the whole time. VS Code helps you edit it. The Terminal lets you give a command. Node.js executes the JavaScript.
