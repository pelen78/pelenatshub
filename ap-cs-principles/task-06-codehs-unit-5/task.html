What You Will Learn

Throughout Unit 5, you will learn how to break a program into smaller pieces that you can use again and again. Instead of repeating code, you will write a function once and call it with different inputs.

01

Functions & Parameters

  • Write a function to group code that does one job, then call it by name.
  • Add parameters so the same function can work with different values.
  • Call one function many times with different arguments, like drawing many shapes in different colors and places.
02

Return Values

  • Use return to send a value back from a function.
  • Store a returned value in a variable or use it in another expression.
  • Tell the difference between a function that prints or draws and one that returns a result.
03

Input, Output & Existing Algorithms

  • Use user input as the arguments for your functions.
  • Show the result of a function as program output.
  • Reuse functions you already wrote to build bigger programs.
