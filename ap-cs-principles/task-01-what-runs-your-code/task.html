Part 2 · Try the Tools

Now use VS Code, the Terminal, and Node.js on the same file.

  1. Create the file in VS Code. On your Desktop, create a folder called ap-csp. Open that folder in VS Code. Create a file called hello.js and save it.

hello.js

let name = "your name";
console.log("Hello, " + name);
Role check → VS Code = EDITOR. Has the program run yet? No. VS Code helped you write and save the source code, but it did not execute it.
  1. Now open the Terminal. In VS Code, go to Terminal → New Terminal. Use the Terminal only after your file has been created and saved.
  2. Check that Node.js is installed. Type the command below and press Enter.
Role check → Terminal = OTHER. The Terminal is not the editor, compiler, or interpreter in this activity. It gives you a place to type the command that tells another tool what to do.

Terminal

node --version

If you see a version number, Node.js is installed.

  1. Check that the Terminal can see your file. Type:

Terminal

ls

You should see hello.js in the list.

  1. Run the JavaScript file with Node.js. Type:

Terminal

node hello.js
Hello, your name
Role check → Node.js = INTERPRETER ROLE for this activity. Node.js reads and executes the JavaScript in hello.js. You did not create a separate executable file first.
Where is the compiler? In this activity, you do not use a separate compile-first step that creates an executable program for you. That difference is part of what you are learning to recognize.
