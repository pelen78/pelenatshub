What is programming?

A computer cannot think for itself. It only does what someone tells it to do.

Programming means writing instructions for a computer. These instructions are called code. The person who writes code is a programmer.

Example: When you tap "play" on a video, the app follows code a programmer wrote: "When this button is tapped, start the video."

Without instructions, a computer is just a box that does nothing.

2

What is an algorithm?

An algorithm is a list of steps to finish a task. The steps must be clear and in the right order.

Think of a recipe. If you put the cake in the oven before you mix it, it does not work.

Example: making a bowl of cereal
  1. Get a bowl.
  2. Pour the cereal.
  3. Pour the milk.
  4. Get a spoon.

Computers follow algorithms too. Their steps must be very exact, because a computer does exactly what you say.

3

What is a flowchart?

A flowchart is a drawing of an algorithm. It uses shapes and arrows to show the steps in order.

Programmers draw a flowchart before they write code. It helps them plan and find mistakes early. Each shape has its own job:

Start / End

Oval. Shows where the flowchart begins and ends.

Process

Rectangle. An action or step, like "pour the milk."

Decision

Diamond. A yes or no question, like "Is the bowl full?"

Input / Output

Parallelogram. Information going in or coming out.

Flowline / Arrow

Arrow. Shows which step comes next.

4

What is a programming language?

People talk in Spanish or English. Computers need their own languages too.

A programming language is a set of words and rules we use to write code a computer can understand. There are many, and each one is good for different things:

  • Scratch: games and animations made with blocks.
  • Python: simple games, apps and robots.
  • JavaScript: websites you can click and interact with.
  • Lua: games inside Roblox.
  • C#: video games made with Unity.
  • Swift: apps for iPhone and iPad.
5

What is debugging?

A bug is a mistake in the code. It can make a program crash, freeze or do the wrong thing.

Debugging means finding the bug and fixing it.

Every programmer makes bugs, even experts. Debugging is how a program goes from "almost works" to "works."

Fun fact: In 1947, Grace Hopper's team found a real moth stuck inside a computer. They wrote that they had "debugged" the machine.
6

How do computers store information?

Inside a computer there are millions of tiny switches. Each switch can only be on or off.

Computers write this with two numbers: 0 and 1. This is called binary code. Each 0 or 1 is called a bit.

With lots of bits together, a computer can store letters, photos, music and games.
