Before You Start

Overview

What's this about?

Soon you will write code in CodeHS. First, you need a few ideas that programmers use all the time.

Today you research programming, algorithms, flowcharts, programming languages, debugging and binary code.

  1. Open a new Google Doc.
  2. Name it lastname_code
  3. Type your name, the date and your class at the top.
  4. Answer every question with complete sentences, in your own words.
Research rule. You can use the Internet to research. Do not copy and paste definitions. Read, understand, then explain it in your own words.
Research and Answer

Answer these 7 questions in your Doc. Use complete sentences. Add examples when the question asks for them.

Read: Quick Reads for Questions 1 to 6 →

Need help? Quick Reads has short readings with what you need for Questions 1 to 6. Read it, then write your answers in your own words.
01

What is programming?

Explain in your own words what computer programming means.

  • What does a programmer tell a computer to do?
  • Why do computers need instructions?
02

What is an algorithm?

Explain what an algorithm is in your own words.

Then write an everyday algorithm: list the steps to complete a task.

Examples: making a sandwich, logging into a computer, brushing your teeth, or getting ready for school.

03

What is a flowchart?

Explain what a flowchart is and why programmers use them.

Then make a table in your Doc for these 5 flowchart symbols. For each one, write its name, its shape, and what it means.

SymbolYour table should include
Start / EndName, shape, and what it means
ProcessName, shape, and what it means
DecisionName, shape, and what it means
Input / OutputName, shape, and what it means
Flowline / ArrowName, shape, and what it means
04

What is a programming language?

Explain what a programming language is.

Give 3 examples of programming languages. For each one, name one kind of project or program you could make with it.

05

What is debugging?

Explain what a bug is in programming and what debugging means.

Why is debugging an important part of programming?

06

How do computers store information?

Explain what binary code is and why computers use 0s and 1s.

  • What does 0 usually mean?
  • What does 1 usually mean?
  • A light bulb is one binary digit. What value is a bulb that is OFF?
  • What value is a bulb that is ON?
07

Reflection

Which of these ideas will be most important when you start writing code? Explain why.
