What Is a Path?

A path is the full address of a file: it tells the computer exactly which drive, which folders, and which file to open.

Example path (Windows)

C:\Users\Student\Documents\School\Maths.docx
PartWhat it is
C:\The drive: the disk the file lives on.
Users, Student, Documents, SchoolThe folders, nested inside each other, in order.
MathsThe file name.
.docxThe extension: tells the computer what kind of file it is.
Read it left to right, outside to inside. Each backslash \ moves you one folder deeper, starting from the drive and ending at the file.
Drive Letters (Windows)

What is a drive letter?

A single letter (A through Z) followed by a colon, used to identify one specific storage device or partition. It is always the first thing in a Windows path.

Why is the main drive almost always C?

This goes back to the earliest IBM PCs. Before hard drives were common, computers started programs from floppy disks, and the system reserved A: for the first floppy drive and B: for a second one. When hard drives became standard, they were given the next free letter, C:, and that convention stuck, even though almost no computer has used a floppy disk in decades.

What happened to A and B?

They still technically exist, but almost nothing uses them anymore because floppy disk drives disappeared. Windows simply keeps skipping them out of habit, so most computers jump straight from having no A or B drive to C: as the first one you see.

Your personal drive is not C. C: is reserved for the computer itself: the operating system and the software installed on that machine. Your personal network drive gets a different letter (often something like D:, S:, or Z:, depending on how the school network is set up) because it lives somewhere else and follows your account, not that specific computer.
How macOS Writes Paths

No drive letters at all

macOS does not use letters for drives. Instead, everything (your internal disk, any external drive, any connected server) fits into one single folder structure that starts at the root, written as just /

Forward slashes, not backslashes

Where Windows separates folders with \, macOS (like Linux) uses /

Where your files live

Your personal files live inside your home folder, at /Users/yourusername/, with the familiar Documents, Desktop, and Downloads folders inside it.

Same idea, Mac style

/Users/Student/Documents/School/Maths.docx
Two things change when you rewrite a Windows path the Mac way: (1) the drive letter and colon C: disappear, so you just start at /, and (2) every backslash \ becomes a forward slash /

One sentence to remember

Windows finds a file by drive letter, then folders; Mac finds the same file by folders alone, starting from one root.
