Before You Start

Overview

What's this about?

Every file has two parts: a name and an extension. The extension is the label that tells the computer which program to open.

Today you find out what happens when that label is missing, or when it lies.

  1. Download Task-03-files.zip from Google Classroom.
  2. Extract it to the Desktop. Right click the zip, then Extract All.
  3. Open a new Google Doc. Name it lastname_filemgmt
  4. Type your name, the date and your class at the top.
STOP

Your personal drive

When you log in with your own user on a school computer, you get a personal drive with 8 GB of space that belongs only to you.

Find it: open File Explorer and click This PC. You will see the C drive and, below it, your drive with a different letter. Write that letter down. You need it later.

  • The Desktop and Documents folders belong to the computer you are sitting at.
  • Your personal drive belongs to you. It follows your user, not the machine.
  • If you save to the Desktop and sit at a different computer tomorrow, your work may not be there.

Today you work in the normal computer folders so you can see how they behave. At the end you move everything to your own drive. From now on, that drive is where your class work lives.

Rules

  • Type must be one of: Document, Image, Audio, Video, Plain text.
  • To find the program, right click the file and choose Open with.
  • Turn on file extensions first, or you are guessing.

Windows (classroom)

File Explorer > View > Show > File name extensions

macOS (your laptop)

Finder > Settings > Advanced > Show all filename extensions

Two files will not behave. Do not skip them and do not delete them. Figure out what is really inside each one, fix it, and write what you did in the Notes column. One of the two is hiding a code word. Write that code word at the bottom of your table.
Export, Rename, Move, Prove It

This part is graded on the file itself, not on what is written inside it.

  1. In your Doc: File > Download > PDF Document.
  2. Go to your Downloads folder and find the PDF.
  3. Rename it exactly: lastname_filemgmt_v01.pdf
  4. Move it into your Unit2_Files_Day1 folder. Move, not copy. Downloads must end up empty of this file.
  5. Take a screenshot of that folder with the PDF inside it and the full path visible.
  6. Now move the whole Unit2_Files_Day1 folder from the Desktop to your personal drive, the one you found in This PC. Drag the folder across. Watch what the path at the top changes to.
  7. Upload the PDF and the screenshot to Google Classroom.
Careful with step 6. When you drag a folder to a different drive, Windows copies it instead of moving it. Check the Desktop afterwards. If the folder is still there, delete the Desktop copy so you only have one.
